Where is my save file?

Each slot is its own file, user1.dat to user4.dat, usually in:

Windows
%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight Silksong\<id>\
macOS
~/Library/Application Support/unity.Team-Cherry.Silksong/<id>/
Linux / Steam Deck
~/.config/unity3d/Team Cherry/Hollow Knight Silksong/<id>/

<id> is a numeric folder named after your platform account. Paths can differ by store or launcher.
